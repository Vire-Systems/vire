This is a brief error code doc. Won't be high detail.
Base the official docs on these error codes.

FORMAT: [VIRE LAYER]-[SUBSYSTEM]-[ERROR]

[VIRE LAYER]
  |
  ├ IN: Internal
  |
  ├- VC: Vire Core
  |   |
  |  [SUBSYSTEM]
  |   |
  |   ├- SC: Scheduler
  |   ├- GC: Garbage Collector
  |   ├- WK: Worker
  |   └- VD: Validation
  |
  ├- VMW: Vire MiddleWare
  |
  └- VU: Vire Upload

* VC-IN-UNEXPECTED_INTERNAL_ERROR - Broad except / Unexpected error

* VC-IN-GIT_PROVIDER_API_FAILED:
   - Failed to fetch files from Git provider's raw file CDN
   - Provider's API sent a malformed git tree. 

* VC-IN-002 - No image

* VC-SC-NO_JOB_STATE - No job state. Job state for requested job uuid was not found.
* VC-SC-CONTAINER_TIMED_OUT - Job terminated for exceeding the 5 minute limit.


* VC-VD-UNSUPPORTED_FRAMEWORK - Unsupported/Invalid framework error

* VC-VD-INVALID_BRANCH:
   - Branch does not exist. It was either removed or parsed incorrectly.
   - Invalid branch error. The branch which was provided to VD does not exist

* VC-VD-INVALID_VIRE_TOML - Invalid vire.toml structure / values
* VC-VD-UNSUPPORTED_GIT_PROVIDER - Unsupported git provider (Internal parsing failure if provider in supported list)

* VC-VD-EMPTY_LOCKFILE - Empty lockfile. 
* VC-VD-NO_LOCKFILE - No lockfile
* VC-VD-UNSUPPORTED_PM:
   - Unsupported package manager
   - The provided PM's lockfile does not match the one in user's repository.

* VC-VD-INVALID_OUTPUT_DIRECTORY:
   - Invalid output directory. Can only contain values from 0-9, a-z, A-Z, _ (underscores) and - (hyphens)

* VC-VD-INVALID_PACKAGE_JSON:
   - Invalid package.json. Remove “preinstall”, “postinstall”, “install”, “prepare”, “prepublish” scripts if present.


* CONTAINER_REAPED - Worker / Container process was collected by garbage collector for exceeding 5m 15s.
    Suggested fixes:
        1. Check for unoptimized dependencies. Check for that by using 'webpack-bundle-analyzer'.
        2. Use speed measure plugin (speed-measure-plugin) to find what the bottleneck is.
